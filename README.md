# MiniShop

Console shop application in C++. 

## Features
- Showing shop's assortment.
- Buying, adding, deleting, finding products.
- Changing products amount.
- Calculating total stock value, total money spent.

## What I learned
- Class Product with private fields, getters and checks inside methods.
- Const methods where needed.
- Saving and loading data from files (fstream).
- Input validation.
- Case-insensitive search.

## How to run 
Open .sln file in Visual Studio, then press F5.
